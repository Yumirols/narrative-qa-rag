## 2. T14 实现（`src/judge.py`，666 行）

- **rubric v1**（计划 §3 基线落地）：独立评审员系统提示（"只评不答"，严禁材料外知识）；
  总分 1~5 五档锚定（5 可直接采用 / 3 部分正确有遗漏 / 1 错误或主要靠猜测）+ 忠实性/完整性/
  简洁性三维 + hallucination 布尔 + **citations 逐条语义支持性**（判"被引原文是否支持答案
  断言"，区别于规则层只验存在性的 entry_valid_rate）；**拒答不扣忠实性**（verdict=unknown
  且证据确实不足 → faithfulness=5，防"诚实的不知道"被误罚；证据充分却拒答仍给低 completeness）。
- **few-shot 2 例全自编**（书房找日记 5 分例 + 编造"地下室哭声"幻觉 2 分例），零评测集内容，
  防泄漏沿 generate 纪律；消息布局 `[system, 例1问/答, 例2问/答, 实际案例]`——前缀逐字节
  稳定，DeepSeek 前缀缓存实测命中：关臂 79,488/167,094（47.6%）、开臂 47,488/169,501（28.0%）。
- **证据确定性重建**：judge 输入的 top-5 证据 = retrieval_results 该生成臂 top 按 rank 前 5，
  与 `generation_log.retrieved_chunk_ids` **逐题核对两臂各 54/54 一致**（judge 评的正是该 run
  生成时实际用的证据，含告警不静默）。
- **确定性纪律**：`judge_metrics.json` 零非确定字段（全部由 details 评分与缓存回放 usage 推导），
  时间/环境/CLI 参数收 `judge_run_log.json`（沿 details/metrics 与 log 分离惯例）；LLM 规格
  复用 generation.llm（deepseek-flash，temperature=0、thinking 关、json_object，max_tokens
  收紧 512——独立缓存命名空间）；解析失败重试一次附纠错提示（沿 generate 模式），实测
  108+2 次调用**零重试零解析失败**。
- **`--sample N`（seed=0）**：两臂从各自 54 题抽相同 11 题（Q03/Q23/Q31/Q34/Q36/Q37/Q38/
  Q42/Q54/Q56/Q83），人工四列 + notes 留空待填。
- **`--audit` 模式**（T15.4）：交叉表纯脚本零 LLM；仅审计目标逐例一次调用（审计模板 v1，
  独立于评审 rubric）。
- **冒烟（T14.4，`--limit 5`，$0.001957 谷）**：5/5 一次解析成功；区分度实证——Q05 金标块在
  第 5 证据位在场而模型仍拒答，judge 正确打 2 分（忠 4/完 1/简 4，issues 精确点名"证据5
  说明山岭交通事故"），对照 Q02 命中金标正确作答拿 5 分——拒答口径两端校准；citations 人工
  核对 3 题判定合理（Q03 双引用分别支撑两段断言，语义支持性而非存在性）。**v1 无需修改，
  未升版直接放量。**

## 3. T15.1 双臂结果解读（与检索层互证）

- **增益方向真实、幅度不足**：图谱开检索层 fact/temporal/aggregate R@5 分别 +0.100/+0.070/
  +0.044（T11 实测），judge 层 fact +0.15、temporal **+0.44** 同向——时序题是图谱机制对准的
  题型（扩展路时序邻接 + 卡片规范化转述），答案质量增益最明显；但总分仅 +0.074，主因见下。
- **aggregate 反降 −0.44 是本阶段新发现的失败面**：检索 R@5 反升（+0.044）而答案质量反降，
  与 label_acc 面 Q44/Q50"命中仍翻错"互证——融合/卡片路注入的干扰块在聚合题被**引用**后
  拖累引用支持率（开臂仅有的 2 条不支持引用 Q25/Q80 均在此面）与完整性。机制注记：聚合题
  需要多块证据拼合，top-5 里多一个干扰块的边际伤害大于单证据题——进报告⑥节。
- **hallucination 布尔全 False = 仪器偏保守**：judge 不轻易打幻觉旗（忠实性最低打到 3、
  引用支持率先降），条级支持率是更灵敏的仪器；此局限与"judge 与被评同模型的自评偏差"
  一并声明（已定决策①的三件套：角色隔离 + 20% 人工校准 + 显式声明）。
