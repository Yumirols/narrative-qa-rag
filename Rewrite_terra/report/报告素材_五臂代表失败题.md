## 1. bm25_jieba · semantic_gap 层换说法失效（原理点①后半 → 稠密检索动机）

### Q02 [semantic_gap/fact] 守护者基础训练的最低达标标准是什么？

gold = `seen08000_c084`（原文："负重８０千克…１２个小时内走完６０千米…据说只是最低标准"）。

| 臂 | fh | R@3 | top-3 |
| --- | --- | --- | --- |
| bm25_jieba | None | 0.00 | c284(12.30) / c079(11.88) / c083(11.82)，gold 不在 top-10 |
| bge_small | **3** | 1.00 | c119 / c352 / **c084(0.4583)** |

机制：题面"最低达标标准"是"负重/小时/千米"数字三要素的换说法，词面零重叠——
BM25 的 IDF 加权在无共享判别词时彻底失效（训练相关块靠"训练"这类高频低 IDF 词
反而把 c284/c079/c083 顶上去）；bge 把"达标标准"与数字三要素编码为相近语义，
rank-3 救回。**这是 semantic_gap 层 6 倍反超（0.068→0.386）的单题缩影。**

### Q44 [semantic_gap/yesno] 临终之际，江坂对这位背叛者的抉择表示了赞许吗？

gold = `c427 + c428`。

| 臂 | fh | R@3 |
| --- | --- | --- |
| bm25_jieba | None | 0.00（top-3：c452/c384/c017，全脱靶） |
| bge_small | **1** | 1.00（c428 rank-1、c427 rank-3） |
| bge_base | **1** | 0.50（c427 rank-1） |

机制：题面"临终/背叛者/抉择/赞许"在 gold 里全部以别的说法出现；最干净的
互补案例——BM25 十名开外，两个 bge 臂全部首位命中。

## 2. bge · literal 层专名失守（稠密检索的已知失败模式，与 BM25 互补的另一面）

### Q06 [literal/fact] 瑚太朗在哪里把盖亚可疑举动的报告提交给了谁？

gold = `seen08000_c348`。

| 臂 | fh | R@3 | top-3 |
| --- | --- | --- | --- |
| bm25_jieba | **1** | 1.00 | **c348(28.76)** / c297 / c380 |
| bge_small | 8 | 0.00 | c230(549字✂) / c247(629字✂) / c327(635字✂) |

机制：题面判别词"报告/提交"是词典精确匹配信号，BM25 + user_dict 直接 rank-1；
bge_small 的 top-3 全部是主题相近（盖亚/报告）但更长的**被截尾块**——专名与
动词的判别力被 500+ token 的均值池化稀释，长干扰块挤出 gold（截尾统计见
`truncation_analysis.json`，c230/c247/c327 均在 187 个截尾块之列）。

### Q32 [literal/fact] 在守护者训练的体能测试中，瑚太朗是第几名？

gold = `seen08000_c091`。bm25_jieba fh=1（c091 score=20.90 rank-1）；
bge_small fh=None（top-10 全脱靶，top-1 c353 仅 0.557）。机制同类：
"体能测试/第几名"的词面锚定被稠密空间抹平，训练主题块（c353/c247）淹没 gold。

> 关联量化：literal 层 gold 被截组（B 组）bge_small R@3 = 0.409 vs 未截组 0.667，
> 而 bm25_jieba 反向 0.909 vs 0.750——失守 = 专名判别力本征弱点 × 长文稀释/截尾
> 的联合效应（两机制共线不可分，见 README"已知局限"）。

## 3. 两范式共同失败 · structural 层（阶段四图谱的动机证据）

### Q21 [structural/aggregate] 瑚太朗在潜入与日常安排中都用过哪些假名？

gold = 5 块（c123/c131/c232/c295/c397，散落全篇）。

| 臂 | fh | R@3 | top-3 |
| --- | --- | --- | --- |
| bm25_jieba | None | 0.00 | c392 / c084 / c124 |
| bge_small | None | 0.00 | c229 / c247 / c235 |
| bge_base | None | 0.00 | c124 / c221 / c379 |

机制：聚合题的答案散在 5 个场景，任何单块都不含完整答案；检索器各自返回
"假名/代号/安排"主题相近的错误场景块。三臂全 0——**chunk 级检索的世界观
（独立段落）承载不了跨场景聚合**，这是图谱增强（实体-场景索引 + 事件时间线）
的直接动机。

### Q89 [structural/aggregate] 在超人能力分类系统中，江坂、瑚太朗、今宫、长居、三国和路易斯分别是哪一类？

gold = 6 块。bm25_jieba R@3=0.33（c094 rank-1、c099 rank-3）、bge_small 0.17、
bge_base 0.00——多 gold（6 块）叠加 R@3 装不下（天花板 3/6=0.5）；且 gold
c094 的证据行落在该 chunk 512 token 截尾之后（截尾 C 组），bge 的向量里根本
没有这段证据。**多 gold 聚合 × 截尾的双重失败样本。**

## 4. w2v_avg · 全臂垫底的代表（原理点②前半：静态词向量三缺陷）

### Q03 [literal/fact] 拜恩带剑绿地骑士团是什么？

gold = `seen08000_c113`。bm25_jieba fh=1（c113 score=11.21 rank-1）；
**w2v_avg fh=None**（top-1 c151 仅 0.718，gold 不在 top-10）。

机制：专名"拜恩带剑绿地骑士团"是低频 OOV/近 OOV 词，本语料训练的 w2v 要么
没有该词向量、要么向量由极少上下文训练而来无区分度；平均池化再把它与
"骑士团/战斗"主题的高频块（c151/c145/c152）混同。与 Q06 同层对照可见
"词典匹配（BM25）> 上下文编码（bge）> 静态平均（w2v）"的完整梯度。

## 使用说明

- 引用格式建议：错误分析小节按"失败模式 → 代表题 → 机制 → 下一阶段方案"组织，
  本文件四节正好对应：换说法失效（→稠密动机）、专名失守（→混合召回动机）、
  跨场景聚合（→图谱动机）、静态向量三缺陷（→上下文表示动机）。
- 复现：`python - <<'EOF'` 读 `runs/<ts>/retrieval_results.json` 按 qid 索引即可
  （任何 20261025 三跑目录数字一致）；截尾标记查同目录 `truncation_analysis.json`
  的 `per_question.<qid>.detail`。
